# Project governance

Recall Lab is maintained by **Solohkg**. The maintainer sets the direction of this official repository and decides which changes and releases to accept.

## Project goals

- Keep the toolkit itself free for students, with AI access and provider costs explained separately.
- Support source-grounded study and active recall.
- Preserve student privacy and keep personal study data out of this repository.
- Prefer understandable, maintainable features over unnecessary complexity.

## Contributions and control

Issues and pull requests are proposals. Opening a proposal does not grant write access, require its acceptance, or change the roadmap. Changes to the official version require the maintainer's approval. Contributors should discuss substantial changes before implementing them.

Forks are independent versions maintained by their respective owners; a fork does not change this repository. This governance document does not restrict or replace the permissions granted by the MIT License.
